# 공간 지시서 예시 둘 — 모양만

> **모양만 — 이 물건·분위기·캐릭터를 후보로 쓰지 않는다.** 이 파일은 `2-4-stay-space.md` §4.2 틀로 지시서를 **다 쓴 뒤에만** 연다(§4.3 2번). 열면 참고 분위기·데이터 물건·소품·캐릭터에서 이 예시와 같은 낱말이 몇 개 겹치는지 세고, 셋 이상이면 그 항목들을 그 서비스 문서에서 다시 짓는다(§4.3 3번). 공간 에이전트에게는 넘기지 않는다.

두 예시는 일부러 성격을 반대로 골랐다 — 틀은 같고 내용은 서비스마다 다르다는 것을 보이려는 것이다.

| | 예시 1 — 창가 찻집 | 예시 2 — 놀이공원 안내 지도 |
|---|---|---|
| 그리기 방식 | 3D(코드로 만든 모형) | 2D 손그림 지도(SVG) |
| 캐릭터 | 있음 — 사용자의 분신 | 없음에 가까움 — 아주 작은 안내원 하나 |
| 공간 화면 | 첫 화면(로그인 뒤) | 첫 화면 |
| 이어받은 것 | 2-3 파격판의 3D 은유 | 2-3 파격판의 지도 은유 |
| 줄마다 붙은 근거 | 줄여 적었다 | 줄여 적었다 |

## 목차

1. [예시 1 — 창가 찻집 (트윈팅)](#1-예시-1--창가-찻집-트윈팅)
2. [예시 2 — 놀이공원 안내 지도 (아이쿵)](#2-예시-2--놀이공원-안내-지도-아이쿵)

## 1. 예시 1 — 창가 찻집 (트윈팅)

트윈팅은 내 부캐(나를 닮게 만든 AI 분신)가 다른 사람의 부캐와 대신 데이트하고, 사용자는 그 데이트를 지켜보며 리포트를 받는 서비스다.

```markdown
# 공간 지시서 — 창가 찻집 (트윈팅)

## 0. 이 공간
- 자리: S-홈(첫 화면, 로그인 뒤) `/home`
- 왜 값어치인가: 「내 부캐의 데이트를 연애 예능처럼 지켜보는 재미」를 첫 화면에서 바로 준다 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 탁자(데이트) 중 하나를 골라 다가가 들여다본다 — 근거: 화면 목록 홈의 주 행동
- 그리기 방식: 3D(코드로 만든 모형) — 근거: 2-3 파격판 「창가 찻집 미니어처」 이어받음
- 이어받는 것: 「4」 제목 서체·브랜드 면, 파격판 은유 「탁자 하나 = 데이트 하나」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 늦은 오후 동네 찻집을 위에서 들여다보는 미니어처 모형(빛·구도), 연애 예능 촬영장의 따뜻한 조명(빛) — 근거: intent 「3」 연애 예능
- 시점: 위에서 비스듬히(약 35도) 내려다봄, 손가락으로 좌우로만 조금 돌림
- 빛: 창으로 들어오는 해 질 녘 주황빛 + 탁자마다 작은 등불, 그림자는 부드럽게 번짐
- 재질: 결이 보이는 나무 바닥·탁자, 천 소파, 유리 찻잔, 벽 타일
- 모서리: 모든 가구 둥글게 — 장난감 모형처럼
- 늘 도는 움직임: 찻잔 김 오름, 창밖 나뭇잎 흔들림, 등불 깜빡임, 부캐가 가끔 고개를 돌림
- 공간 팔레트: 따뜻한 중간 채도(나무·크림·올리브·벽돌), 지금 고른 탁자 밑 고리만 강조색
- 밀도: 가운데 탁자 자리는 비우고 벽·창가·구석을 소품으로 채움

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 상태별 | 근거 |
| 데이트 하나 | 탁자 하나와 상대 부캐 | 진행 중: 두 부캐가 앉아 찻잔 김 / 끝남: 빈 자리 위 접힌 쪽지(리포트) / 다음 단계 원함: 탁자 위 꽃 한 송이 | 화면 목록 홈, 저장·조회 코드 dates |
| 케미 점수 | 쪽지의 리본 길이 | 점수가 높을수록 리본이 길다 | 리포트 필드 score |
| 내 부캐 | 창가 자리의 부캐(캐릭터) | 아침형이면 커피, 저녁형이면 와인잔 | 부캐 만들기 답 필드 |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 벽 메모판 | 말투 맞추기에서 고친 부캐 말버릇 쪽지가 붙어 있다 | 가까이 — 쪽지 글(장식) |
| 책장 | 연애관 답에서 나온 책 제목 셋 | 가까이 — 책등 |
| 창밖 거리 | 만날 조건의 지역 이름이 적힌 간판 | 가까이 |
| 출입문 종 | 새 데이트가 시작되면 울린다 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 창가 고양이를 세 번 누름 | 고양이가 부캐 무릎으로 옮겨 감 | 저장 없음 |
| 두 잔을 길게 누름 | 잔이 부딪히는 효과음(소리를 켰을 때만) | 저장 없음 |
### 2-4 빈 데이터일 때
빈 탁자 셋에 「예약석」 팻말, 부캐가 문 쪽을 바라봄 → 글 층의 「만날 조건 정하기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 사용자의 부캐 — 근거: intent 「1」 부캐
- 만드는 법: 둥근 도형 조합(머리·몸·팔), 부캐 만들기의 성격 답으로 옷 색과 소품
- 평소: 창가에 앉아 찻잔을 듦, 가끔 다른 탁자를 봄
- 물건을 고르면: 그 탁자로 걸어가 옆에 섬
- 데이터에 따라: 데이트가 끝날 때마다 메모판 쪽지가 하나 는다

## 4. 누르면 무슨 일
| 끝난 데이트 탁자 | 등불이 밝아짐 | 부캐가 걸어가고 카메라가 탁자로 내려감 | 찻잔 두 개의 남은 양, 접힌 쪽지의 리본, 상대 부캐의 표정 | 쪽지가 펼쳐지며 리포트 요약 3줄(글 층) + 「리포트 보기」 주 버튼 | 바깥을 누르면 카메라가 돌아옴 |

## 5. 어떻게 늘릴지
- 1개: 탁자 하나, 10개: 1층 가득 + 2층 다락, 넘치면 「지난 데이트 앨범」 책장으로 묶음
- 공간이 여럿: 데이트 상황(첫 카페 대화·여행 계획·주말 약속)마다 장소가 다를 수 있음 — 처음엔 찻집 하나, 같은 틀로 다른 장소를 더하는 자리만 둠

## 6. 그래도 지킬 것
- 글자: 상대 이름·점수·리포트 요약은 글 층
- 신호 자리: 지금 고른 탁자 밑 고리만 강조색
- 동작 줄이기: 카메라 고정, 김·등불 정지, 누르면 바로 요약
- 대신 화면: WebGL 없음 → 같은 구도 정지 그림 + 데이트 목록
- 대체 경로: 공간 아래 「목록으로 보기」
- 소리: 효과음 — 기본 꺼짐, 켜는 단추는 글 층 오른쪽 위
- 성능: 탁자 20개 상한(넘치면 묶음), 폰은 그림자 품질 낮춤
- 새 기능 후보: 다른 사람 찻집 구경 가기(공유)
```

## 2. 예시 2 — 놀이공원 안내 지도 (아이쿵)

아이쿵은 AI 크리에이터가 만든 결과물과 만드는 방법을 공개하면 참가자가 따라 만들며 배우는 챌린지와, 상금을 건 콘테스트가 있는 서비스다. 다루는 분야가 다섯이다.

```markdown
# 공간 지시서 — 놀이공원 안내 지도 (아이쿵)

## 0. 이 공간
- 자리: S-01(첫 화면) `/`
- 왜 값어치인가: 「길고 비싼 강의 대신 챌린지 한 개 단위로 짧게 직접 만들어 보는 것」 — 오늘 탈 놀이기구를 고르듯 챌린지를 골라 들어가는 재미 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 구역(분야)·표지판(챌린지)·무대(콘테스트) 중 하나를 골라 다가간다 — 근거: 화면 목록 S-01의 주 행동, intent 「5」 플로우
- 그리기 방식: 2D 손그림 지도(SVG) — 근거: 2-3 파격판 「놀이공원 안내 지도」 이어받음, 폰에서도 가벼운 쪽
- 이어받는 것: 「4」 제목 서체·글자 로고, 파격판 은유 「구역 = 분야, 놀이기구 표지판 = 인기 챌린지, 축제 무대 = 콘테스트」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 입구에서 나눠 주는 접이식 종이 안내 지도(구도·재질), 색연필로 칠한 동네 축제 포스터(색) — 근거: 2-3 대담판 겉모습(종이 결 질감)
- 시점: 위에서 내려다본 평면 지도, 구역 경계는 굽은 길
- 빛: 그림자 없음 — 종이 위 인쇄처럼 평평하게, 접힌 자국만 옅게
- 재질: 접힌 자국이 있는 두꺼운 종이, 색연필 칠, 인쇄 잉크 선
- 모서리: 구역 경계는 손으로 그린 둥근 선, 표지판은 나무 팻말 모양
- 늘 도는 작은 움직임: 회전목마 깃발 펄럭임, 축제 무대 조명 깜빡임, 길 위 점선이 천천히 흐름(입구 → 고른 곳)
- 공간 팔레트: 분야마다 색연필 한 색(채도 중간, 명도 밝음) + 길·글자는 잉크색. 강조색은 고른 표지판 테두리와 입구에서 그곳까지의 길에만
- 밀도: 구역마다 빈 터를 남겨 표지판이 늘어날 자리를 둠

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 상태별 | 근거 |
| 분야 다섯 | 지도의 구역 다섯 | 챌린지 있음: 구역 이름 팻말 / 없음: 「공사 중」 울타리 | 저장·조회 코드 category |
| 인기 챌린지 | 구역 안 놀이기구 표지판(순위 · 참가 N명 줄 서기 팻말) | 자리보다 많으면 구역 이름 옆 「+N」 | 인기순 조회, 필드 participants |
| 진행 중인 콘테스트 | 지도 오른쪽 축제 무대(상금 깃발 · 남은 날) | 마감 임박: 깃발에 남은 날 / 없음: 무대 막이 내려감 | 콘테스트 조회, 필드 prize·endsAt |
| 검색 | 입구 옆 안내소 | — | 화면 목록 S-31 |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 입구 매표소 | 「오늘 처음 오셨나요?」 — 첫 챌린지 추천 칸 | 가까이 — 매표소 창 |
| 구역 사이 벤치 | 지난주 완주한 사람 수가 새겨진 명판 | 가까이 — 명판 글(장식) |
| 분수대 | 새로 올라온 챌린지가 있으면 물이 솟음 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 광장 「놀이기구 뽑기」 기계를 누름 | 챌린지 하나가 무작위로 골라져 그 표지판까지 길이 그려짐 | 저장 없음 |
| 회전목마 깃발을 세 번 누름 | 깃발 색이 다섯 분야 색으로 차례로 바뀜 | 저장 없음 |
### 2-4 빈 데이터일 때
모든 구역에 「공사 중」 울타리, 무대 막이 내려감 → 글 층 「첫 챌린지 올리기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 없음에 가까움 — 지도의 주인공은 고르는 사용자 자신이다. 안내소 창 안에 아주 작은 안내원 하나만(누르면 손을 흔듦) — 근거: intent 「2」 참가자가 「무엇부터 해야 할지 모를 때」 연다
- 만드는 법: 선 그림 몇 획
- 물건을 고르면: 안내원은 움직이지 않고, 입구에서 고른 곳까지 점선 길이 그려짐

## 4. 누르면 무슨 일
| 놀이기구 표지판 | 표지판이 살짝 흔들리고 강조색 테두리 | 입구에서 그곳까지 점선 길이 그려지며 지도가 그 구역으로 확대 | 줄 서기 팻말의 참가자 수, 표지판 그림(결과물 미리보기), 순위 리본 | 챌린지 요약 카드가 아래에서 올라옴(글 층) + 「챌린지 보기」 주 버튼 | 지도 바깥이나 닫기를 누르면 확대가 풀림 |

## 5. 어떻게 늘릴지
- 챌린지가 늘 때: 구역마다 표지판 자리 상한, 넘치면 구역 이름 옆 「+N」 → 누르면 그 분야 목록
- 공간이 여럿: 분야마다 「구역 안 상세 지도」를 같은 틀로 더할 자리 — 처음엔 전체 지도 하나
- 새 분야가 생기면: 빈 터에 구역 하나를 더함

## 6. 그래도 지킬 것
- 글자: 챌린지 제목·참가자 수·상금은 글 층
- 신호 자리: 고른 표지판 테두리와 길만 강조색
- 동작 줄이기: 깃발·조명·점선 흐름 정지, 누르면 확대 없이 바로 카드
- 대신 화면: 해당 없음(SVG) — 대체 경로는 그대로
- 대체 경로: 지도 아래 「목록으로 보기」(본 화면의 인기순 목록)
- 키보드: 구역 이름 다섯 → 표지판(순위 차례) → 뽑기 → 무대 깃발 → 전체 보기 → 안내소
- 소리: 없음
- 성능: 한 번에 지도 한 장만 그림
- 새 기능 후보: 내가 완주한 놀이기구 표지판에 작은 깃발 표시(저장 필요)
```
