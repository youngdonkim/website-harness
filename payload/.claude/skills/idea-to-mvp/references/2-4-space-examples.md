# 공간 지시서 예시 둘 — 모양만

> **모양만 — 이 물건·분위기·캐릭터를 후보로 쓰지 않는다.** 이 파일은 `2-4-stay-space.md` §4.2 틀로 지시서를 **다 쓴 뒤에만** 연다(§4.3 2번). 열면 참고 분위기·데이터 물건·소품·캐릭터에서 이 예시와 같은 낱말이 몇 개 겹치는지 세고, 셋 이상이면 그 항목들을 그 서비스 문서에서 다시 짓는다(§4.3 3번). 공간 에이전트에게는 넘기지 않는다.

두 예시는 **지어낸 서비스**다 — 실제 프로젝트를 예로 들면 그 프로젝트에서 2-4를 돌릴 때 예시가 곧 답이 되어 버린다. 성격도 일부러 반대로 골랐다 — 틀은 같고 내용은 서비스마다 다르다는 것을 보이려는 것이다.

| | 예시 1 — 내 베란다 온실 | 예시 2 — 놀이공원 안내 지도 |
|---|---|---|
| 누구의 어떤 장소인가 | 사용자 자신의 공간 | 서비스 안의 장소(사용자는 손님) |
| 그리기 방식 | 3D(코드로 만든 모형) | 2D 손그림 지도(SVG) |
| 캐릭터 | 있음 — 안내하는 존재(고양이 정원사) | 없음에 가까움 — 아주 작은 안내원 하나 |
| 공간 화면 | 첫 화면(로그인 뒤) | 첫 화면 |
| 이어받은 것 | 2-3 파격판의 3D 은유 | 2-3 파격판의 지도 은유 |
| 줄마다 붙은 근거 | 줄여 적었다 | 줄여 적었다 |

## 1. 예시 1 — 내 베란다 온실 (가상 서비스 「잎새」)

「잎새」는 집에서 키우는 식물마다 물 준 날·햇빛·새 잎을 기록하고, 물 줄 때를 알려 주는 식물 돌봄 앱이다(지어낸 서비스).

```markdown
# 공간 지시서 — 내 베란다 온실 (잎새)

## 0. 이 공간
- 자리: S-홈(첫 화면, 로그인 뒤) `/home`
- 왜 값어치인가: 「식물이 자라는 걸 보는 즐거움」을 기록 목록이 아니라 화분이 늘어선 베란다로 준다 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 화분(식물) 중 하나를 골라 다가가 들여다본다 — 근거: 화면 목록 홈의 주 행동
- 누구의 어떤 장소인가: 사용자 자신의 베란다 — 근거: intent 「1」 「내가 키우는 식물」. 그래서 내 기록(물 준 날·사진)을 물건으로 늘어놓아도 된다
- 그리기 방식: 3D(코드로 만든 모형) — 근거: 2-3 파격판 「창가 베란다 미니어처」 이어받음
- 이어받는 것: 「4」 제목 서체·브랜드 면, 파격판 은유 「화분 하나 = 식물 하나」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 아침 햇살이 드는 유리 온실 사진(빛), 식물도감 세밀화의 차분한 색(색) — 근거: intent 「3」 자라는 걸 보는 즐거움
- 시점: 위에서 비스듬히(약 35도) 내려다봄, 손가락으로 좌우로만 조금 돌림
- 빛: 오전 햇빛이 유리창으로 비스듬히, 화분 그림자는 부드럽게
- 재질: 테라코타 화분, 젖은 흙과 마른 흙, 유리, 나무 선반, 물뿌리개의 함석
- 모서리: 화분·선반 모두 둥글게 — 장난감 모형처럼
- 늘 도는 움직임: 잎이 바람에 살짝 흔들림, 유리창 물방울이 천천히 흘러내림, 햇빛 자리가 하루 시간 따라 옮겨 감
- 공간 팔레트: 초록·흙색·테라코타 중심의 중간 채도, 지금 고른 화분 밑 받침 테두리만 강조색
- 밀도: 선반 칸마다 화분 하나, 빈 칸은 「새 식물 자리」로 남김

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 상태별 | 근거 |
| 식물 하나 | 화분 하나와 그 식물 | 물 줄 때 지남: 흙이 옅고 잎이 처짐 / 오늘 물 줌: 흙이 짙고 물받침에 물 / 새 잎 기록: 연두색 새순 | 저장·조회 코드 plants, 필드 lastWatered |
| 물 준 기록 수 | 화분 옆 물뿌리개 눈금 | 이번 달 물 준 횟수만큼 눈금이 참 | 필드 waterings |
| 식물 사진 | 화분 앞 작은 액자 | 가장 최근 사진 한 장(견본 사진) | 필드 photos |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 달력 | 다음에 물 줄 날에 동그라미 | 가까이 — 이번 주 물 줄 식물 수(글 층) |
| 씨앗 봉투 상자 | 「새 식물 더하기」로 이어지는 빈 봉투들 | 가까이 — 글 층에 「새 식물 더하기」 테두리 버튼 |
| 창밖 날씨 | 오늘 날씨가 창밖에 — 햇빛이 센 날은 블라인드가 내려감 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 고양이 정원사를 세 번 누름 | 고양이가 물뿌리개를 들고 한 바퀴 돎 | 저장 없음 |
| 화분을 길게 누름 | 잎을 쓰다듬듯 흔들림 + 짧은 바스락 효과음(소리를 켰을 때만) | 저장 없음 |
### 2-4 빈 데이터일 때
빈 화분 셋과 씨앗 봉투 상자, 고양이가 상자를 가리킴 → 글 층의 「첫 식물 더하기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 안내하는 존재 — 고양이 정원사 — 근거: intent 「2」 「물 줄 때를 자꾸 잊는 사람」에게 알려 주는 역할
- 만드는 법: 둥근 도형 조합(머리·몸·꼬리), 얼굴은 점 두 개
- 평소: 선반 사이를 천천히 걷다가 물 줄 때가 지난 화분 옆에 앉음
- 물건을 고르면: 고른 화분 옆으로 걸어가 앉음
- 데이터에 따라: 물 줄 때가 지난 화분이 많을수록 고양이가 바쁘게 오감

## 4. 누르면 무슨 일
| 화분 | 잎이 살짝 흔들림 | 고양이가 걸어가고 카메라가 화분으로 내려감 | 흙의 젖은 정도, 새순, 액자 속 최근 사진 | 식물 이름·마지막 물 준 날·다음 물 줄 날(글 층) + 「물 줬어요」 주 버튼 | 바깥을 누르면 카메라가 돌아옴 |

## 5. 어떻게 늘릴지
- 1개: 화분 하나, 10개: 선반 두 단 가득, 넘치면 「온실 안쪽」 선반으로 묶고 「더 보기」 목록
- 공간이 여럿: 방마다 다른 창가(거실·부엌) — 처음엔 베란다 하나, 같은 틀로 다른 창가를 더하는 자리만 둠

## 6. 그래도 지킬 것
- 글자: 식물 이름·날짜·물 줄 때는 글 층
- 신호 자리: 지금 고른 화분 받침 테두리와 주 버튼만 강조색
- 동작 줄이기: 카메라 고정, 잎·물방울·고양이 정지, 누르면 바로 내용
- 대신 화면: WebGL 없음 → 같은 구도 정지 그림 + 식물 목록
- 대체 경로: 공간 아래 「목록으로 보기」
- 소리: 효과음 — 기본 꺼짐, 켜는 단추는 글 층 오른쪽 위
- 성능: 화분 20개 상한(넘치면 묶음), 폰은 그림자 품질 낮춤
- 새 기능 후보: 친구의 베란다 구경 가기(공유)
```

## 2. 예시 2 — 놀이공원 안내 지도 (가상 서비스 「한판」)

「한판」은 동네의 원데이 클래스(하루짜리 체험 수업)를 요리·공예·운동·음악·그림 다섯 분야로 모아, 이번 주에 들을 수업을 고르게 하는 서비스다(지어낸 서비스). 분야마다 인기 수업이 있고, 수강생 작품을 모아 여는 주말 발표회가 있다.

```markdown
# 공간 지시서 — 놀이공원 안내 지도 (한판)

## 0. 이 공간
- 자리: S-01(첫 화면) `/`
- 왜 값어치인가: 「이번 주에 뭘 해 볼까」를 고르는 재미 — 오늘 탈 놀이기구를 고르듯 수업을 골라 들어간다 — 근거: intent 「3」
- 어디를 볼지 고르는 장소인가: 사용자가 구역(분야)·표지판(수업)·무대(발표회) 중 하나를 골라 다가간다 — 근거: 화면 목록 S-01의 주 행동, intent 「5」 플로우
- 누구의 어떤 장소인가: 서비스 안의 놀이공원 — 사용자는 손님. 그래서 사용자 자신의 기록(들은 수업·찜한 수업)을 공원의 시설로 늘어놓지 않고, 그것은 「내 수업」 화면 몫으로 둔다 — 근거: 화면 목록
- 그리기 방식: 2D 손그림 지도(SVG) — 근거: 2-3 파격판 「놀이공원 안내 지도」 이어받음, 폰에서도 가벼운 쪽
- 이어받는 것: 「4」 제목 서체·글자 로고, 파격판 은유 「구역 = 분야, 놀이기구 표지판 = 인기 수업, 축제 무대 = 발표회」 — 바꾸지 않음

## 1. 어떤 세계로 보일지
- 참고 분위기: 입구에서 나눠 주는 접이식 종이 안내 지도(구도·재질), 색연필로 칠한 동네 축제 포스터(색) — 근거: 2-3 대담판 겉모습(종이 결 질감)
- 시점: 위에서 내려다본 평면 지도, 구역 경계는 굽은 길
- 빛: 그림자 없음 — 종이 위 인쇄처럼 평평하게, 접힌 자국만 옅게
- 재질: 접힌 자국이 있는 두꺼운 종이, 색연필 칠, 인쇄 잉크 선
- 모서리: 구역 경계는 손으로 그린 둥근 선, 표지판은 나무 팻말 모양
- 늘 도는 작은 움직임: 회전목마 깃발 펄럭임, 축제 무대 조명 깜빡임, 길 위 점선이 천천히 흐름(입구 → 고른 곳)
- 공간 팔레트: 분야마다 색연필 한 색(채도 중간, 명도 밝음) + 길·글자는 잉크색. 강조색은 고른 표지판 테두리와 입구에서 그곳까지의 길에만
- 밀도: 구역마다 빈 터를 남겨 표지판이 늘어날 자리를 둠

## 2. 무엇으로 채울지
### 2-1 데이터를 맡은 물건
| 데이터 | 물건 | 상태별 | 근거 |
| 분야 다섯 | 지도의 구역 다섯 | 수업 있음: 구역 이름 팻말 / 없음: 「공사 중」 울타리 | 저장·조회 코드 category |
| 인기 수업 | 구역 안 놀이기구 표지판(순위 · 남은 자리 줄 서기 팻말) | 자리보다 많으면 구역 이름 옆 「+N」 | 인기순 조회, 필드 seatsLeft |
| 이번 주 발표회 | 지도 오른쪽 축제 무대(날짜 깃발) | 임박: 깃발에 남은 날 / 없음: 무대 막이 내려감 | 발표회 조회, 필드 startsAt |
| 검색 | 입구 옆 안내소 | — | 화면 목록 검색 화면 |
### 2-2 이야기 소품 (일부)
| 소품 | 이야기 | 누르면 |
| 입구 매표소 | 「오늘 처음 오셨나요?」 — 처음 듣기 좋은 수업 추천 칸 | 가까이 — 매표소 창 |
| 구역 사이 벤치 | 지난주 수업을 마친 사람 수가 새겨진 명판 | 가까이 — 명판 글(장식) |
| 분수대 | 새로 열린 수업이 있으면 물이 솟음 | 숨은 재미 |
| …(8~15개까지) | | |
### 2-3 숨은 재미
| 광장 「놀이기구 뽑기」 기계를 누름 | 수업 하나가 무작위로 골라져 그 표지판까지 길이 그려짐 | 저장 없음 |
| 회전목마 깃발을 세 번 누름 | 깃발 색이 다섯 분야 색으로 차례로 바뀜 | 저장 없음 |
### 2-4 빈 데이터일 때
모든 구역에 「공사 중」 울타리, 무대 막이 내려감 → 글 층 「첫 수업 열기」 주 버튼

## 3. 누가 사는지
- 캐릭터: 없음에 가까움 — 지도의 주인공은 고르는 사용자 자신이다. 안내소 창 안에 아주 작은 안내원 하나만(누르면 손을 흔듦) — 근거: intent 「2」 「무엇부터 해 볼지 모를 때」 연다
- 만드는 법: 선 그림 몇 획
- 물건을 고르면: 안내원은 움직이지 않고, 입구에서 고른 곳까지 점선 길이 그려짐

## 4. 누르면 무슨 일
| 놀이기구 표지판 | 표지판이 살짝 흔들리고 강조색 테두리 | 입구에서 그곳까지 점선 길이 그려지며 지도가 그 구역으로 확대 | 줄 서기 팻말의 남은 자리, 표지판 그림(수강생 작품 미리보기), 순위 리본 | 수업 요약 카드가 아래에서 올라옴(글 층) + 「수업 보기」 주 버튼 | 지도 바깥이나 닫기를 누르면 확대가 풀림 |

## 5. 어떻게 늘릴지
- 수업이 늘 때: 구역마다 표지판 자리 상한, 넘치면 구역 이름 옆 「+N」 → 누르면 그 분야 목록
- 공간이 여럿: 분야마다 「구역 안 상세 지도」를 같은 틀로 더할 자리 — 처음엔 전체 지도 하나
- 새 분야가 생기면: 빈 터에 구역 하나를 더함

## 6. 그래도 지킬 것
- 글자: 수업 제목·남은 자리·날짜는 글 층
- 신호 자리: 고른 표지판 테두리와 길만 강조색
- 동작 줄이기: 깃발·조명·점선 흐름 정지, 누르면 확대 없이 바로 카드
- 대신 화면: 해당 없음(SVG) — 대체 경로는 그대로
- 대체 경로: 지도 아래 「목록으로 보기」(본 화면의 인기순 목록)
- 키보드: 구역 이름 다섯 → 표지판(순위 차례) → 뽑기 → 무대 깃발 → 전체 보기 → 안내소
- 소리: 없음
- 성능: 한 번에 지도 한 장만 그림
- 새 기능 후보: 내가 들은 수업 표지판에 작은 깃발 표시(저장 필요)
```
