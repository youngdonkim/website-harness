# 견본 지도 틀

화면 목록에 **지도가 들어가는 화면**(주변 장소 찾기, 위치 고르기 등)이 있을 때, 키·가입 없이 지도를 띄우는 부품 틀이다. 지도가 없는 서비스는 아무것도 깔지 않는다.

- **무엇으로** — MapLibre GL JS(지도를 그리는 오픈소스 라이브러리, `maplibre-gl`)와 OpenFreeMap 공개 스타일(지도 모양과 타일을 주는 무료 서버). API 키도 가입도 없다.
- **쓰지 않는 것** — OpenStreetMap 공식 타일 서버(`tile.openstreetmap.org`)는 자동으로 대량 요청을 보내는 것을 정책으로 막고 있다. `react-leaflet`은 흔치 않은 라이선스를 쓰고 있어 쓰지 않는다.
- **이 지도는 견본이다** — 공개 무료 서버라 사용량 보장이 없다. 실서비스에서 쓸 지도(국내 지도 서비스 등 키가 필요한 것)는 4단계 준비에서 정하고, 그때 `sample-map.tsx`를 갈아끼운다.

## 파일

| 틀 파일 | 프로젝트에 넣는 자리 |
|---|---|
| `sample-map.tsx.template` | `src/components/sample-map.tsx` — 지도 부품. 이름과 좌표를 받아 지도와 마커를 그린다 |

## 넣는 차례

2-1 주요 화면 단계에서, 화면 목록에 지도가 들어가는 화면이 있을 때만 첫 화면 에이전트가 한다 (`2-1-mockup.md` §2.6.2 「견본 지도」).

1. **앱 의존성으로 깐다** — `npm install --save-exact maplibre-gl`. 개발 의존성(`-D`)이 아니다 — 실서비스 화면이 쓰는 라이브러리라서다. 판은 그때의 최신 stable로 고정하고, 고른 판은 `package.json`이 기록한다.
2. **일꾼 파일 복사를 `package.json` 스크립트로 묶는다** — 일꾼 파일(Web Worker — 지도 그리는 일을 따로 맡는 보조 프로그램)은 라이브러리 폴더에 있다. 번들러가 그 위치를 못 찾으니 `public/`에 복사해 두고 부품이 주소를 직접 알려 준다(`setWorkerUrl`). 안 하면 개발 중엔 몰라도 실서비스 빌드에서 지도가 영영 안 뜬다. 라이브러리 판이 바뀌면 복사본도 같이 바뀌어야 하니 사람이 기억하지 않게 스크립트로 묶는다:
   ```json
   "scripts": {
     "copy:map-worker": "node -e \"require('fs').copyFileSync('node_modules/maplibre-gl/dist/maplibre-gl-worker.mjs','public/maplibre-gl-worker.mjs')\"",
     "postinstall": "npm run copy:map-worker",
     "predev": "npm run copy:map-worker",
     "prebuild": "npm run copy:map-worker"
   }
   ```
   이미 `postinstall`·`predev`·`prebuild`가 있으면 `&&`로 이어 붙인다. 복사본은 `npm install`이 매번 만드니 `.gitignore`에 `/public/maplibre-gl-worker.mjs`를 더해 올리지 않는다.
3. **부품을 놓는다** — `sample-map.tsx.template`을 `src/components/sample-map.tsx`로 복사한다. 지도가 있는 화면에서만 import한다 — 부품이 라이브러리를 동적 import(필요할 때 내려받기)로 불러서, 지도 없는 화면의 번들에는 안 섞인다. 첫 화면 등 다른 화면에서 이 부품을 import하면 그 화면 번들에 들어가니 피한다.
   - 지도 칸에는 높이가 꼭 있어야 한다. 앱 셸(상단 로고 줄) 안에서는 `h-dvh`가 아니라 `h-full`로 부모를 따르게 한다.
   - 마커 모양은 서비스 토큰 클래스(`bg-foreground` 등)로 정한다. hex 값을 쓰지 않는다.
   - 오른쪽 아래 출처 표시(OpenFreeMap · OpenMapTiles · OpenStreetMap)는 지도 사용 조건이다. 지우지 않는다.
4. **견본 장소 데이터를 저장·조회 코드에 둔다** — 장소 이름과 좌표(`[경도, 위도]`)는 예시 콘텐츠처럼 그럴듯하게 지어서 저장·조회 코드(`src/lib/storage.ts`)의 견본 데이터에 넣는다. 화면에 박지 않는다. **주소 검색은 「견본 장소 목록에서 찾기」로 흉내 낸다** — 입력한 글자로 견본 장소의 이름·주소를 걸러 보이는 것이다. 공개 주소 검색 서비스(Nominatim)는 부르지 않는다. 초당 1회 제한과 자동완성 금지가 정책이라, 글자를 칠 때마다 부르는 화면이 금지에 걸린다. 진짜 주소 검색은 실서비스 지도를 정하는 4단계 준비에서 함께 정한다.
5. **설계 결정 기록(ADR — `mvp/adr.md`)에 한 줄 적는다** — 「지도는 지금 견본 지도(OpenFreeMap, 키 없음). 실서비스 지도 교체는 4단계 준비에서 정한다.」
6. **확인한다** — 타입 검사·린트·빌드를 돌린다. 빌드 결과로 지도 라이브러리 조각이 지도 화면의 번들에만 있는지 본다. 화면에서 지도가 뜨는지는 사람이 본다. 그림 찍기(`npm run canvas:shots`)는 지도 칸의 `data-map-ready="1"`을 기다렸다 찍는다 — 목업 캔버스 틀 README의 「그림 찍기」.

## 알아 둘 것

- 지도가 그려지고 나면 부품이 지도 칸에 `data-map-ready="1"`을 단다(그리는 중에는 `"0"`). 그림 찍기 스크립트가 이 표시를 기다린다. 타일 요청이 한 번이라도 막히면 이 표시가 영영 안 달리니, 기다리는 쪽에는 상한이 있다.
- 목업 캔버스는 지도 화면의 창을 여러 개 띄운다. 캔버스가 실제 화면으로 바뀌는 창을 동시에 몇 개로 제한해서 브라우저의 그래픽 자원 한도에는 걸리지 않는다.
- 지도는 `?state=`를 모른다. 빈·로딩·오류 상태의 지도 칸은 저장·조회 코드가 주는 결과(빈 장소 목록 등)로 화면이 그린다.
- 지명이 영어로 나오면 한글 우선 코드(`name:ko`)가 빠졌는지 본다.
