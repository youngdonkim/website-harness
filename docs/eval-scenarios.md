# eval 시나리오 — 실사고 재현 색인

하네스의 지시 문서(스킬·에이전트·rules)는 AI의 행동을 바꾸는 프로그램이다. 코드에 회귀 테스트(regression test — 고쳤던 문제가 다시 생기는지 확인하는 검사)가 있듯, 지시 문서를 고칠 때도 "예전에 났던 사고가 다시 나지 않는지"를 확인할 목록이 필요하다. 이 파일이 그 목록이다.

- **언제 쓰나** — 스킬·에이전트·rules를 크게 고칠 때(문장 다듬기 수준 말고, 절차·규칙이 바뀔 때). 고치는 파일이 걸린 행을 찾아 "고친 뒤에도 같은 상황에서 같은 방어가 작동하나?"를 자문한다. 답이 애매하면 그 시나리오를 머릿속으로 한 번 돌려보고, 방어가 약해졌으면 고치기 전에 보완한다.
- **어떻게 자라나** — 새 실사고가 나면 여기 한 줄 추가한다. 사고 원문(정황·실측 값)은 각 지시 문서에 그대로 남는다 — **이 목록은 색인이지 이사 갈 곳이 아니다.** 원문을 여기로 옮기지 않는다.
- **왜 자동이 아니라 수동인가** — 1인 사용 하네스라 자동 평가 스위트는 유지 비용이 이득보다 크다. 대신 "고칠 때 되짚는다"를 저장소 규칙(AGENTS.md)으로 적어 잊지 않게 한다.
